ШАХМАТЁР 4.7 — СБОРКА APK ЧЕРЕЗ GITHUB

1. На github.com войдите в свой аккаунт.
2. Создайте новый репозиторий: + -> New repository, имя chessweeper-android, Public или Private -> Create repository.
3. На странице репозитория нажмите «uploading an existing file» или Add file -> Upload files.
4. Распакуйте этот ZIP на компьютере и загрузите ВСЕ файлы и папки из него в корень репозитория, включая скрытую папку .github (она содержит workflow).
   Важно: в GitHub папка .github/workflows/build-apk.yml должна быть именно в корне репозитория.
5. Нажмите Commit changes.
6. Откройте вкладку Actions -> Build Chessweeper APK -> Run workflow (если автоматическая сборка уже запущена, дождитесь её).
7. Откройте завершённый запуск и внизу в разделе Artifacts скачайте Chessweeper_4_7_APK.zip.
8. Распакуйте ZIP: внутри будет app-debug.apk. Перенесите на Android и установите.

Это DEBUG APK, подписанный автоматически отладочным ключом GitHub runner. Для личной установки подходит. При следующей сборке ключ может измениться, и Android может потребовать удалить старое приложение (это удалит данные приложения). Перед обновлением экспортируйте сохранение в игре.

Если workflow не появляется: убедитесь, что файл .github/workflows/build-apk.yml загружен, а Actions разрешены в настройках репозитория.
