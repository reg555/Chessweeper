ШахмаТёр 4.7 — исходный Android-проект.
Откройте папку проекта в Android Studio, дождитесь Gradle Sync, затем Build > Build Bundle(s) / APK(s) > Build APK(s).
Файл APK появится в app/build/outputs/apk/debug/app-debug.apk.
Для установки разрешите установку из выбранного источника на Android.
Сохранения HTML-браузера автоматически не переносятся: используйте экспорт и импорт.
Для сборки нужны Android SDK 35, JDK 17 и Gradle через Android Studio.
